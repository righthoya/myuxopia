# 기본 팝업 목록과 문구

## 1. 목적
서비스마다 반복해서 들어가는 팝업을 목록으로 정리하고, 제목·본문·버튼 문구를 바로 복사해 쓰게 한다. 문구는 합니다체로 쓰고, 프로젝트마다 바뀌는 값은 `{변수}`로 둔다.

## 2. 팝업 유형
| 유형 | 언제 | 버튼 | 등급 |
|---|---|---|---|
| 얼럿 (Alert) | 결과·안내만 전달, 사용자 선택 없음 | 1개: [확인] | 필수 |
| 컨펌 (Confirm) | 실행 전에 사용자 결정 필요 | 2개: [취소] [실행 동사] | 필수 |
| 경고 컨펌 (Destructive) | 되돌릴 수 없는 작업 (삭제·탈퇴·초기화) | 2개: [취소] [삭제] — 실행 버튼 경고색 | 필수 |
| 입력 팝업 (Prompt) · 2차 | 실행 전에 사유·값 입력 필요 (개인정보 조회 사유 등) | 2개: [취소] [실행 동사], 입력 전 실행 비활성 | 선택 |
| 토스트 (Toast) | 가벼운 완료 알림, 확인 불필요 | 없음, {노출 시간: 3초} 후 사라짐 | 권장 |

## 3. 공통 규칙
| 항목 | 내용 | 등급 |
|---|---|---|
| 버튼 문구 | 실행 버튼은 '확인' 대신 동작을 쓴다 (삭제, 저장, 로그아웃) | 필수 |
| 버튼 순서 | 왼쪽 취소 · 오른쪽 실행으로 서비스 전체 통일 (2026-10-05 확정) | 필수 |
| 제목 | 무엇에 관한 팝업인지 한 줄. 질문형은 컨펌에만 사용 | 권장 |
| 본문 | 결과와 다음 행동을 2줄 이내로. 되돌릴 수 없으면 반드시 명시 | 필수 |
| 닫기 | 얼럿·컨펌은 ESC로 닫힘(=취소). 경고 컨펌은 바깥 클릭으로 닫히지 않음 | 필수 |
| 포커스 | 열릴 때 팝업 안으로 이동, 닫히면 원래 버튼으로 복귀. 경고 컨펌의 기본 포커스는 [취소] | 필수 |
| 중첩 | 팝업 위에 팝업을 띄우지 않는다. 필요하면 앞 팝업을 닫고 연다 | 권장 |
| 완료 알림 | 단순 완료는 토스트, 다음 행동이 필요하면 얼럿 | 권장 |

## 4. 1차 MVP 팝업 (13종) — 먼저 구현
기준: 모든 서비스에 공통으로 필요하고, MVP 기능 정책(회원가입·로그인·문의·오류)과 바로 연결되는 것

| # | 상황 | 유형 | 제목 | 본문 | 버튼 |
|---|---|---|---|---|---|
| S1 | 세션 만료 예고 | 컨펌 | 곧 자동 로그아웃됩니다 | {남은 시간: 5분} 후 자동으로 로그아웃됩니다. 계속 이용하려면 연장해 주십시오. | 로그아웃 / 연장 |
| S2 | 세션 만료됨 | 얼럿 | 로그아웃되었습니다 | 오랫동안 사용하지 않아 자동으로 로그아웃되었습니다. 다시 로그인해 주십시오. | 로그인 |
| S3 | 작성 중 이탈 | 경고 컨펌 | 작성을 그만두시겠습니까? | 저장하지 않은 내용은 사라집니다. | 계속 작성 / 나가기 |
| S4 | 권한 없음 | 얼럿 | 접근 권한이 없습니다 | 이 메뉴를 이용할 권한이 없습니다. 필요하면 관리자에게 문의해 주십시오. | 확인 |
| S6 | 서버 오류 | 얼럿 | 일시적인 오류가 발생했습니다 | 잠시 후 다시 시도해 주십시오. 문제가 계속되면 {문의 채널}로 알려 주십시오. (오류 코드: {코드}) | 확인 |
| A1 | 로그아웃 | 컨펌 | 로그아웃하시겠습니까? | — | 취소 / 로그아웃 |
| A2 | 로그인 실패 누적 | 얼럿 | 로그인할 수 없습니다 | 비밀번호를 {횟수: 5회} 잘못 입력해 계정이 잠겼습니다. 비밀번호를 재설정해 주십시오. | 비밀번호 재설정 |
| A6 | 회원가입 완료 | 얼럿 | 회원가입이 완료되었습니다 | {서비스명}을 이용할 수 있습니다. | 시작하기 |
| D2 | 저장 완료 | 토스트 | — | 저장되었습니다. | — |
| D3 | 삭제 확인 | 경고 컨펌 | {대상}을 삭제하시겠습니까? | 삭제한 내용은 되돌릴 수 없습니다. | 취소 / 삭제 |
| D6 | 필수값 누락 | 얼럿 | 입력하지 않은 항목이 있습니다 | {항목명}을 입력해 주십시오. | 확인 |
| D8 | 파일 업로드 제한 | 얼럿 | 파일을 올릴 수 없습니다 | {허용 형식: jpg, png, pdf} 파일만 {최대 용량: 10MB}까지 올릴 수 있습니다. | 확인 |
| N1 | 문의 등록 완료 | 얼럿 | 문의 등록이 완료되었습니다 | 문의번호는 {문의번호}입니다. 답변은 {답변 채널}로 알려 드립니다. | 확인 |

- S6 서버 오류는 S5 네트워크 오류 문구를 함께 쓸 수 있게 {원인 문구}를 변수로 둔다

## 5. 2차 MVP 팝업 (19종) — 내용 보관, 구현은 나중
기준: 특정 정책(비밀번호 주기·탈퇴·개인정보 조회·약관 개정)이 확정되거나 서비스 유형에 따라 필요한 것

| # | 상황 | 유형 | 제목 | 본문 | 버튼 |
|---|---|---|---|---|---|
| S5 | 네트워크 오류 | 얼럿 | 연결이 원활하지 않습니다 | 인터넷 연결을 확인한 뒤 다시 시도해 주십시오. | 다시 시도 |
| S7 | 점검 예정 안내 | 얼럿 | 서비스 점검 안내 | {점검 일시}에 서비스 점검이 진행됩니다. 점검 중에는 이용할 수 없습니다. | 확인 / 오늘 하루 보지 않기 |
| S8 | 새 버전 적용 | 컨펌 | 새 버전이 있습니다 | 최신 기능을 쓰려면 화면을 새로고침해 주십시오. | 나중에 / 새로고침 |
| A3 | 중복 로그인 | 컨펌 | 다른 기기에서 로그인 중입니다 | 여기서 로그인하면 다른 기기는 로그아웃됩니다. | 취소 / 로그인 |
| A4 | 비밀번호 변경 주기 | 컨펌 | 비밀번호를 변경해 주십시오 | 비밀번호를 {변경 주기: 90일} 동안 변경하지 않았습니다. | 다음에 변경 / 변경하기 |
| A5 | 비밀번호 변경 완료 | 얼럿 | 비밀번호가 변경되었습니다 | 새 비밀번호로 다시 로그인해 주십시오. | 로그인 |
| A7 | SNS 계정 연결 | 컨펌 | 이미 가입된 이메일입니다 | 같은 이메일로 가입된 계정이 있습니다. 기존 계정에 연결하시겠습니까? | 취소 / 연결하기 |
| A8 | 회원 탈퇴 | 경고 컨펌 | 정말 탈퇴하시겠습니까? | 탈퇴하면 {삭제 대상: 이용 내역과 저장한 정보}가 삭제되며 되돌릴 수 없습니다. | 취소 / 탈퇴 |
| D1 | 저장 확인 | 컨펌 | 저장하시겠습니까? | — | 취소 / 저장 |
| D4 | 일괄 삭제 | 경고 컨펌 | 선택한 {개수}건을 삭제하시겠습니까? | 삭제한 내용은 되돌릴 수 없습니다. | 취소 / 삭제 |
| D5 | 선택 없음 | 얼럿 | 선택된 항목이 없습니다 | {작업}할 항목을 먼저 선택해 주십시오. | 확인 |
| D7 | 수정 취소 | 컨펌 | 수정을 취소하시겠습니까? | 변경한 내용은 저장되지 않습니다. | 계속 수정 / 수정 취소 |
| D9 | 처리 중 이탈 | 얼럿 | 처리 중입니다 | 작업이 끝날 때까지 화면을 닫지 마십시오. | 확인 |
| P1 | 마스킹 해제 | 입력 팝업 | 개인정보 조회 사유 | 개인정보를 조회하려면 사유를 입력해 주십시오. 조회 기록은 저장됩니다. | 취소 / 조회 |
| P2 | 개인정보 포함 다운로드 | 입력 팝업 | 다운로드 사유 | 개인정보가 포함된 파일입니다. 사유를 입력해 주십시오. 다운로드 기록은 저장됩니다. | 취소 / 다운로드 |
| P3 | 마케팅 수신 동의 변경 | 얼럿 | 수신 동의가 변경되었습니다 | {변경 일시}에 {채널} 수신을 {동의/거부}했습니다. | 확인 |
| P4 | 약관 개정 동의 | 컨펌 | 이용약관이 변경되었습니다 | {시행일}부터 변경된 약관이 적용됩니다. 내용을 확인하고 동의해 주십시오. | 약관 보기 / 동의 |
| N2 | 문의 연속 등록 제한 | 얼럿 | 잠시 후 다시 등록해 주십시오 | 짧은 시간에 여러 건을 등록할 수 없습니다. | 확인 |
| N3 | 알림 권한 요청 | 컨펌 | 알림을 받으시겠습니까? | {알림 내용: 처리 결과와 중요 공지}를 알림으로 보내 드립니다. | 나중에 / 알림 받기 |

## 6. 체크리스트
- [ ] 실행 버튼이 '확인'이 아니라 동작 이름인가
- [ ] 되돌릴 수 없는 작업에 경고 컨펌을 썼는가
- [ ] 버튼 순서가 서비스 전체에서 같은가
- [ ] 본문이 2줄 이내이고 다음 행동을 알려 주는가
- [ ] ESC·포커스 이동이 규칙대로 동작하는가

## 7. 확정·검토
- 확정 (2026-10-05): 버튼 순서 왼쪽 취소 · 오른쪽 실행
- 확정 (2026-10-05): 1차 MVP 13종 / 2차 19종 구분. 1차 유형은 얼럿·컨펌·경고 컨펌·토스트, 입력 팝업은 2차
- 검토: 결제·예약 취소 등 서비스별 팝업은 2단계 정책 카테고리와 함께 추가
