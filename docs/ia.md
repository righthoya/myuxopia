확정 2026-09-25 · 개정 2026-10-05 (UX 정책서로 성격 정리: 파운데이션·컴포넌트 제외, 팝업 메뉴 신설) · MVP 데스크톱 웹 · 1순위 사용자: 프로덕트 디자이너

## 1. 메뉴 구조
```
[로고 = 홈/시작하기]   상단: 변경 이력 · 커피챗 · ☕ 후원 (통합검색은 2차 MVP)

홈 정책 목록: 분류 탭 없이 한 목록 + 제목 검색. 각 줄에 '분류 / 묶음' 표시   (메뉴 정의: app/utils/menu.ts)

1. UX 정책
   └ (항목 없음, '준비 중')   ← 목적과 방향은 홈 히어로 문구로 이동

2. 기능 정책 (9개, 유형 태그 필터: 공통·B2B·플랫폼·B2C·공공 — 상세 policy-categories.md)
   ├ 계정: 회원가입 · 로그인 · 비밀번호 · 권한
   ├ 탐색: 검색·필터링            ← 피그마 B
   ├ 운영: 알림 · 문의 지원        ← 문의 = 피그마 C
   └ 데이터·보안·법: 개인정보 처리 · 오류·장애 처리 (에러 화면 403·404·500 포함)

3. 팝업·문구                      ← 2026-10-05 신설 (상세 popups.md)
   └ 팝업 목록: 팝업 유형 · 공통 규칙(문구 가이드: 톤·안내·오류·빈 상태 포함) · 1차 MVP 13종 · 2차 19종
```
- 개정 (2026-10-07): 화면 패턴 메뉴 삭제(헤더·푸터 삭제, 에러 화면은 오류·장애 처리로 합침), 문구 가이드는 팝업 목록 공통 규칙으로 합침, 접근성 메뉴 삭제(기준은 각 정책의 '접근성' 행), 정책 목록 분류 탭 삭제(구분할 항목이 적음), 로그인·회원가입은 기능 정책 / 계정으로 이동, 메뉴명 변경(권한·역할 → 권한, 문의·고객 지원 → 문의 지원)
- 제외 (2026-10-05): 파운데이션(컬러·타이포·간격·그리드·아이콘), 컴포넌트 17종 → UI 정책서 영역. UX 정책서로 한정
- 설계자 부록: 화면설계서 작성 요소, 명칭 규정
- 기능 정책 페이지의 예시 문구 중 팝업은 '팝업·문구'의 팝업 번호(S1, A3 등)로 링크
- 로그인·알림 정책 참고 재료: 세션 만료(경고+연장), 회원/비회원(문의 정책), 권한별 메뉴 노출(PPTX 규칙6), 이메일 알림(PPTX 이메일 타입), 화면 알림(컨펌·얼럿)

## 2. 공통 화면 구성
- 좌측 2depth 사이드바 · 우측 '이 페이지 목차'
- 페이지 상단에 **버전 · 최종 수정일** 표기 (업데이트 때마다 갱신). 복사 내용에는 출처·버전을 붙이지 않음

## 3. 상세 페이지 틀
- 정책: 목적 → 규칙 표 → 흐름도 → 예시 문구 → 체크리스트
- 팝업: 유형 → 공통 규칙 → 목록 표(상황·유형·제목·본문·버튼) → 체크리스트, 팝업마다 복사 버튼

## 4. 페이지 공통 요소 (복사·붙여넣기로 다른 프로젝트를 빨리 시작하기 위한 요소, 별도 메뉴 아님)
1. **복사 버튼**: 전체 복사 / 항목별 복사 (형식: 일반 텍스트 · 표 · 마크다운)
2. **변수 컬러 강조**: 프로젝트마다 바꿀 값은 `{보관 기간: 30일}` 형태로 강조색 배경 + 괄호·밑줄 병행(색만으로 구분 금지). 복사 시 `{ }` 그대로 유지
3. **등급 배지**: 필수(반드시 준수) / 권장(기본 준수, 사유 있을 때 변경) / 선택(프로젝트에 따라 포함). '필수만 복사' 버튼
4. **피그마 연결**: '피그마에서 열기' 링크 + 클릭 시 불러오는 피그마 임베드 미리보기(보기 권한 필요). 피그마에 생기기 전까지 '준비 중'

## 5. 확장 단계 메모
- 의견·피드백: 프로젝트에서 개선한 내용을 원본 페이지에 제안 → 담당자가 피그마 원본에 반영
