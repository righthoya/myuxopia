# 개인정보 처리 정책

## 1. 목적
사용자의 개인정보를 필요한 만큼만 수집하고 안전하게 표시·관리할 수 있도록 수집·동의, 표시·마스킹, 열람·수정·삭제, 보관·파기·보안 기준을 하나로 정의한다. (웹 데스크톱 기준)
- 범위: 수집 항목·목적 안내 → 동의·기록 → 화면 표시(마스킹) → 열람·수정·철회·탈퇴 → 보관·파기 → 이력 관리
- 다른 정책으로 넘김: 가입 단계 약관 동의(→ 회원가입), 원문 조회 권한(→ 권한), 오류 화면의 개인정보 노출 금지(→ 오류·장애 처리), 팝업 문구(→ 팝업·문구 P1~P4)

| 수집·동의 | 동의 기록 | 공통 | 동의 일시와 약관 버전을 기록한다. 약관이 바뀌면 다시 동의를 받는다 (팝업 P4) | 필수 | — |

| 표시·마스킹 | 원문 조회 | 관리자 | 사유를 입력해야 원문을 볼 수 있고 (팝업 P1), 조회 이력을 남긴다. {재마스킹: 5분}이 지나면 자동으로 다시 가린다 | 필수 | 재마스킹 |
| 표시·마스킹 | 노출 제한 | 공통 | 주소(URL), 알림 본문, 오류 문구에 개인정보를 넣지 않는다 | 필수 | — |
| 열람·수정·삭제 | 내 정보 열람·수정 | 사용자 | 내 정보에서 수집 항목을 열람·수정할 수 있다. 수정할 때는 비밀번호 재입력 등으로 본인을 확인한다 | 필수 | — |
| 열람·수정·삭제 | 동의 철회·회원 탈퇴 | 사용자 | 선택 동의는 철회하면 바로 반영한다 (팝업 P3). 탈퇴 전에 삭제되는 항목과 보관되는 항목을 안내한다 | 필수 | — |

| 보관·파기·보안 | 처리방침 안내 | 공통 | 푸터에 개인정보처리방침 링크를 항상 둔다. 바뀌면 공지하고 개정 이력을 제공한다 | 필수 | — |

## 3. 흐름 (개인정보 수집 동의)
![개인정보 수집 동의 흐름. 진입: 가입·문의 등 개인정보 입력 화면에 들어옵니다. 동의: 수집 항목과 목적을 필수·선택으로 나눠 안내하고, 필수 항목 동의를 확인합니다. 필수 항목에 동의하지 않으면 진행할 수 없다고 안내합니다. 동의하면 선택 항목 동의로 넘어가며 선택 항목은 거부할 수 있습니다. 완료: 동의 일시와 약관 버전을 기록하고 가입·요청 처리를 완료합니다. 동의는 내 정보에서 철회할 수 있습니다.](/flows/privacy.svg)

## 4. 예시 문구 (합니다체)
| 상황 | 문구 |
|---|---|
| 수집 목적 안내 | {항목}은 {수집 목적}을 위해 수집합니다. |
| 선택 항목 안내 | 선택 항목은 동의하지 않아도 서비스를 이용할 수 있습니다. |
| 필수 미동의 | 필수 항목에 동의해야 다음 단계로 진행할 수 있습니다. |
| 약관 재동의 | {시행일}부터 변경된 약관이 적용됩니다. 내용을 확인하고 동의해 주십시오. (팝업 P4) |
| 원문 조회 사유 | 개인정보를 조회하려면 사유를 입력해 주십시오. 조회 기록은 저장됩니다. (팝업 P1) |
| 자동 재마스킹 | 보안을 위해 {재마스킹} 후 다시 가려집니다. |
| 정보 수정 본인 확인 | 정보를 수정하려면 비밀번호를 다시 입력해 주십시오. |
| 동의 철회 완료 | {변경 일시}에 {채널} 수신을 거부했습니다. (팝업 P3) |
| 탈퇴 전 안내 | 탈퇴하면 {삭제 항목}이 삭제됩니다. {보관 항목}은 법령에 따라 {법정 보관 기간} 동안 보관 후 파기됩니다. |
| 처리방침 변경 공지 | 개인정보처리방침이 {시행일}부터 변경됩니다. |

## 5. 체크리스트
- 수집 항목이 목적에 꼭 필요한 것뿐이고, 항목 옆에 목적이 보이는가
- 필수·선택 동의가 나뉘어 있고, 선택 거부 시에도 이용할 수 있는가
- 동의 일시·약관 버전을 기록하고, 약관 변경 시 재동의를 받는가
- 이름·연락처·이메일이 기본 마스킹되는가
- 원문 조회 시 사유 입력·이력 기록·자동 재마스킹이 있는가
- 주소, 알림, 오류 문구에 개인정보가 들어가지 않는가
- 탈퇴 전 삭제·보관 항목을 안내하는가
- 푸터에 개인정보처리방침 링크가 항상 있는가
