# 오류·장애 처리 정책

## 1. 목적
오류나 장애가 생겨도 사용자가 상황을 이해하고 다음 행동을 할 수 있도록 입력 오류, 시스템 오류, 에러 페이지(403·404·500), 점검·장애 안내 기준을 정의합니다.

## 2. 규칙

### 입력 오류 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 인라인 오류 | 입력 필드 바로 아래 문장으로 안내<br>아이콘과 텍스트를 함께 써서 색상만으로 구분하지 않음 | 공통 |
| 오류 문구 | 무엇이 잘못됐는지와 고치는 방법을 함께 안내<br>사용자를 탓하는 표현, 개발 용어 사용 금지 | 공통 |
| 제출 시 처리 | 첫 오류 필드로 초점 이동<br>오류 후에도 입력값 유지 (비밀번호 제외) | 공통 |

### 시스템 오류 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 일시적 오류 | 오류 팝업으로 안내하고 다시 시도 버튼 제공<br>오류 코드를 함께 표시해 문의 시 활용 | 공통 |
| 네트워크 오류 | 인터넷 연결 확인 안내<br>연결이 복구되면 자동 재시도 (추가 제안) | 공통 |
| 중요 작업 오류 | 저장·결제 등 중요한 작업은 처리 결과를 확인할 수 있게 안내<br>처리 중 버튼 비활성으로 중복 실행 방지 | 사용자 |

### 에러 페이지 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 403 권한 없음 | 메뉴·버튼을 숨겨도 URL 직접 입력·북마크·공유 링크·권한 회수 후 새로고침으로 들어올 수 있어 화면 필요<br>비로그인 상태면 403 대신 로그인 화면으로 이동 (로그인 후 원래 페이지 복귀)<br>제목: 접근 권한이 없습니다<br>본문: 이 페이지는 {권한 이름} 권한이 있어야 볼 수 있습니다. 필요하면 관리자에게 요청해 주십시오.<br>버튼: 이전 페이지 · 홈으로 · 권한 요청(선택) | 사용자 |
| 404 페이지 없음 | 주소가 바뀌었거나 삭제된 페이지임을 안내<br>홈 이동과 주요 메뉴 링크 제공 | 공통 |
| 500 서버 오류 | 잠시 후 다시 시도하도록 안내<br>새로고침·홈 이동, 문의 채널과 오류 코드 제공 | 공통 |

### 점검·장애 운영 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 점검 사전 안내 | 점검 일시와 영향 범위를 미리 공지 (예: 3일 전)<br>로그인 후 팝업·배너로 한 번 더 안내 | 공통 |
| 점검 중 화면 | 점검 시간과 종료 예정 시각 안내<br>문의 채널 제공 | 공통 |
| 장애 공지·기록 | 장애 발생 시 공지와 복구 예정 시간 안내<br>오류 로그 기록, 로그와 화면에 개인정보 미포함 | 관리자 |

## 3. 흐름 — 오류 발생 시 처리 플로우
(단계·화면·분기 이름 순서, 연결 관계는 피그마 흐름도 참고)
- 발생·판단
- 안내·재시도
- 복구
- 완료
- 사용자 요청 (화면 이동·저장·조회)
- 오류 발생
- 오류 유형 판단 (입력 / 권한 / 페이지 / 서버)
- 서버·네트워크 오류 팝업 (오류 코드 표시)
- 다시 시도 (입력값 유지)
- 500 에러 페이지·장애 공지 (문의 채널 안내)
- 요청 정상 처리
- 결과 안내 (토스트·완료 화면)
- 작업 이어서 진행
- 원래 화면
- 분기: n회 실패 / 재시도 성공

## 4. 에러 페이지 문구 (톤 A / B)
| 화면 | A. 합니다체 (공공·B2B·금융) | B. 해요체 (B2C·플랫폼) | 버튼 |
|---|---|---|---|
| 403 제목 | 접근 권한이 없습니다 | 이 페이지를 볼 수 있는 권한이 없어요 | — |
| 403 본문 | 이 페이지는 {권한 이름} 권한이 있어야 볼 수 있습니다. 필요하면 관리자에게 요청해 주십시오. | 이 페이지는 {권한 이름} 권한이 있어야 볼 수 있어요. 필요하면 관리자에게 요청해 주세요. | 이전 페이지 · 홈으로 · 권한 요청(선택) |
| 404 제목 | 페이지를 찾을 수 없습니다 | 페이지를 찾을 수 없어요 | — |
| 404 본문 | 주소가 바뀌었거나 삭제된 페이지입니다. 주소를 다시 확인해 주십시오. | 주소가 바뀌었거나 삭제된 페이지예요. 주소를 다시 확인해 주세요. | 홈으로 · 주요 메뉴 |
| 500 제목 | 일시적인 오류가 발생했습니다 | 잠시 문제가 생겼어요 | — |
| 500 본문 | 잠시 후 다시 시도해 주십시오. 문제가 계속되면 {문의 채널}로 알려 주십시오. (오류 코드: {코드}) | 잠시 후 다시 시도해 주세요. 계속 안 되면 {문의 채널}로 알려 주세요. (오류 코드: {코드}) | 새로고침 · 홈으로 |
- 비로그인 상태에서 권한이 필요한 페이지에 들어오면 403이 아니라 로그인 화면으로 보내고, 로그인 후 원래 페이지로 돌아간다
