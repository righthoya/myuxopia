# 회원가입 정책

## 1. 목적
신규 사용자가 최소한의 입력으로 계정을 만들고, 서비스는 필요한 동의와 확인을 빠짐없이 받을 수 있도록 가입 방식, 약관 동의, 정보 입력, 인증·완료 기준을 정의합니다.

## 2. 규칙

### 가입 방식 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 가입 방식 선택 | 서비스 유형에 맞는 방식을 1개 이상 제공 (이메일 / 관리자 발급 / 초대 링크 / SNS)<br>로그인 화면 하단과 헤더에 회원가입 진입 경로 제공 | 비회원 |
| SNS 간편 가입 (추가 제안) | 카카오·네이버·구글 등 서비스 기준에 따라 선택<br>같은 이메일 계정이 있으면 새로 만들지 않고 계정 연결 안내 | 비회원 |
| 관리자 발급·초대 (B2B) | 관리자가 계정을 만들거나 초대 링크 발송<br>첫 로그인 시 비밀번호 설정과 약관 동의 후 이용<br>초대 링크 유효기간 안내 (예: 7일) | 관리자 · 사용자 |

### 약관 동의 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 필수·선택 구분 | 필수와 선택 항목을 구분해 표기하고 항목마다 전문 보기 제공<br>필수 약관 미동의 시 다음 단계 비활성<br>동의서에 들어갈 내용(목적·항목·보유 기간·거부 권리)은 개인정보 정책 참고 | 비회원 |
| 전체 동의 | 전체 동의 제공, 선택 항목이 포함된다는 사실을 문구로 안내<br>전체 동의 후에도 선택 항목 개별 해제 가능 | 비회원 |
| 마케팅 수신·연령 확인 | '광고성 정보 수신 동의'라는 이름으로 필수 약관과 분리해 받고 기본값은 미체크<br>채널별(문자·이메일·앱 푸시) 선택, 앱 푸시 권한 허용과는 별개<br>만 14세 미만은 가입 제한 또는 법정대리인 동의 (B2C·공공)<br>켜고 끄기·재확인은 알림 정책 참고 | 비회원 |

### 정보 입력 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 최소 수집 | 가입에 꼭 필요한 항목만 입력 (예: 이메일, 비밀번호, 이름)<br>그 외 항목은 가입 후 프로필에서 입력 | 비회원 |
| 아이디·비밀번호 | 아이디 중복은 입력을 마친 직후 확인<br>비밀번호 규칙·표시/숨김 토글은 비밀번호 정책 참고 | 비회원 |
| 오류 안내 | 입력 필드 아래 문장으로 오류 안내<br>제출 시 첫 오류 필드로 초점 이동<br>오류·뒤로 가기 후에도 입력값 유지 (비밀번호 제외) | 비회원 |

### 인증·완료 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 본인·이메일 확인 | B2C: 휴대폰 본인확인(인증번호 문자) 기본, 자동 가입 방지를 함께 처리<br>B2B: 관리자 발급·초대 링크로 가입, 이메일 확인만 진행<br>인증번호 유효시간(예: {5분})과 남은 시간 표시, 재발송 {1분에 1회 · 하루 5회} 제한 | 비회원 |
| 중복·자동 가입 방지 | 같은 휴대폰 번호(B2C) 또는 같은 이메일(B2B)로 계정은 1개<br>이미 가입된 경우 로그인·비밀번호 찾기로 안내<br>B2C: 휴대폰 인증으로 자동 가입을 막으므로 CAPTCHA 미사용<br>B2B: 자가 가입 없음, 가입 승인은 관리자가 처리 | 공통 |
| 가입 완료 | 완료 안내 후 자동 로그인 또는 메인 화면 이동<br>관리자 승인이 필요하면 '승인 대기' 상태 안내<br>동의 기록은 개인정보 정책 참고 | 사용자 · 관리자 |

## 3. 흐름 — 회원가입 플로우
(단계·화면·분기 이름 순서, 연결 관계는 피그마 흐름도 참고)
- 진입·약관 동의
- 정보 입력·인증
- 가입 처리
- 완료
- 로그인 화면 (‘회원가입’ 선택)
- 가입 방식 선택 (이메일 / SNS)
- 약관 동의 (필수·선택 구분, 전체 동의)
- 정보 입력 (이메일·비밀번호·이름)
- 인증번호 입력 (유효시간 안내, 재발송 제한)
- 일정 시간 인증 제한 (연속 실패 n회)
- 중복 계정 확인 (이미 가입 시 로그인 안내)
- 가입 처리 (동의 이력 기록)
- 가입 완료 안내 (승인 필요 시 승인 대기)
- 메인 화면
- 분기: n회 실패 / 인증 성공

## 4. 예시 문구 (A. 합니다체 기준)
| 상황 | 문구 |
|---|---|
| 전체 동의 | 전체 동의합니다. (선택 항목 포함) |
| 필수 미동의 | 필수 약관에 동의해야 가입할 수 있습니다. |
| 이메일 형식 오류 | 이메일 형식이 올바르지 않습니다. 예: name@example.com |
| 이메일 중복 | 이미 가입된 이메일입니다. 로그인하거나 비밀번호를 찾아 주십시오. |
| 인증 코드 발송 | {이메일}로 인증 코드를 보냈습니다. {유효 시간} 안에 입력해 주십시오. |
| 인증 코드 오류 | 인증 코드가 일치하지 않습니다. 다시 확인해 주십시오. |
| 인증 시간 만료 | 인증 시간이 지났습니다. 인증 코드를 다시 받아 주십시오. |
| 재발송 제한 | 잠시 후 다시 요청해 주십시오. ({남은 시간} 후 가능) |
| 연령 제한 | 만 14세 미만은 가입할 수 없습니다. |
| SNS 계정 연결 | 같은 이메일로 가입된 계정이 있습니다. 기존 계정에 연결하시겠습니까? |
| 가입 완료 | 회원가입이 완료되었습니다. |
| 승인 대기 | 가입 신청이 접수되었습니다. 관리자 승인 후 이용할 수 있습니다. |

## 5. 체크리스트
- [ ] 가입 방식과 {변수} 값을 프로젝트에 맞게 정했는가
- [ ] 필수·선택 약관이 구분되고, 선택 약관 기본값이 미체크인가
- [ ] 연령 확인이 필요한 서비스(B2C·공공)인지 확인했는가
- [ ] B2C는 휴대폰 본인확인, B2B는 관리자 발급·초대로 가입하는가
- [ ] 필수 입력 항목이 최소인가 (가입 후 받아도 되는 항목 제외)
- [ ] 오류가 필드 아래 문장으로 표시되고 첫 오류 필드로 포커스가 가는가
- [ ] 중복 가입 시 로그인·비밀번호 찾기로 이어지는가
- [ ] 인증 코드 유효 시간·재발송 제한이 화면에 보이는가
- [ ] 동의 이력(항목·일시·버전)이 저장되는가
