# 문의 지원 정책

## 1. 목적
문의를 정해진 절차로 등록하고, 관리자가 일관되게 처리하도록 기준을 정합니다.

## 2. 규칙 표
| 유형 | 항목 | 대상 | 내용 | 등급 | {변수} |
|---|---|---|---|---|---|
| 문의 접근 | 로그인 여부별 진입 | 회원 · 비회원 | 회원은 문의 내역으로 바로 연결합니다. 비회원은 이메일과 비밀번호를 등록한 뒤 문의할 수 있습니다 | 필수 | — |
| 문의 접근 | 문의 유형 분류 | 공통 | {문의 유형: 예약 · 결제 · 상품 · 기타}로 분류하고, 필요하면 2단계(1depth·2depth)로 나눕니다 | 필수 | 문의 유형 |
| 문의 접근 | 접근 경로 | 사용자 · 관리자 | 사용자는 GNB·메뉴에서, 관리자는 GNB·대시보드·메뉴에서 들어옵니다 | 권장 | — |
| 문의 작성 | 입력 제약 | 공통 | 제목은 {제목 최대: 50자} 이내, 본문은 {본문 최소: 20자} 이상 입력해야 등록할 수 있습니다. 첨부는 {첨부 제한: jpg·png·pdf, 최대 5개, 10MB 이하}다. 비회원은 이메일과 비밀번호를 반드시 입력하고, CAPTCHA를 적용합니다 | 필수 | 제목 최대, 본문 최소, 첨부 제한 |
| 문의 작성 | 금칙어·운영 안내 | 공통 | 욕설·비방·허위 사실이 포함되면 등록을 제한하고 경고 문구를 보여 줍니다. 등록되더라도 답변하지 않을 수 있음을 작성 화면에 공지합니다 | 필수 | — |
| 접수·처리 | 등록 완료 | 공통 | 접수되면 문의 번호(ID)를 발급하고 '문의 등록이 완료되었습니다' 화면으로 이동합니다 (팝업 N1). 이메일 알림은 선택해 보낼 수 있습니다 | 필수 | — |
| 접수·처리 | 처리 상태 | 공통 | 등록(운영자가 아직 조회하지 않음) → 처리 중(운영자가 조회함) → 완료(답변 후 관리자가 완료 처리) 3단계로 표시합니다 | 필수 | — |
| 문의 이력 | 이력 확인 | 회원 · 비회원 | 회원은 문의 내역에서 처리 상태와 답변을 확인합니다. 비회원은 등록 때 입력한 이메일과 비밀번호를 입력하면 열람할 수 있습니다 | 필수 | — |
| 운영/보안 | 스팸 방지 | 공통 | CAPTCHA로 자동 등록을 막고, {등록 제한: 1분에 2건 이상 불가}로 연속 등록을 제한합니다 (팝업 N2) | 필수 | 등록 제한 |
| 운영/보안 | 완료 문의 보관 | 관리자 | 완료된 문의는 {보관 기간: 90일} 후 삭제합니다. 보관 기간은 당일 · 30일 · 90일 · 365일 중에서 정합니다 | 권장 | 보관 기간 |
| 운영/보안 | 문의 데이터 리포트 | 관리자 | 문의 건수, 처리 시간, 유형별 통계 리포트를 제공합니다 | 권장 | — |
| 운영/보안 | 재문의 | 사용자 | 답변에 이어서 다시 묻는 재문의(대댓글)를 허용할지 정합니다 | 선택 | — |
| 운영/보안 | 관리자 신고 | 관리자 | 다른 관리자가 스팸으로 신고하면 연동합니다. 신고된 문의자는 이후 등록을 제한할 수 있고, 비회원 스팸은 해당 IP의 등록을 막습니다 | 선택 | — |

## 3. 흐름 (문의하기)
![문의하기 흐름. 진입: 로그인 사용자는 바로 문의 등록으로 갑니다. 비회원은 이메일과 임시 비밀번호를 먼저 입력한 뒤 문의 등록으로 갑니다. 등록: 유형 선택, 제목·내용 입력, 파일 첨부, CAPTCHA 인증을 거쳐 등록하면 문의 번호가 발급되고 접수 완료 화면에서 메인으로 이동할 수 있습니다. 처리: 관리자가 문의를 조회하면 처리 중 상태가 됩니다. 완료: 답변 후 관리자가 완료 상태로 바꿉니다.](/flows/inquiry.svg)

## 4. 예시 문구 (합니다체)
| 상황 | 문구 |
|---|---|
| 비회원 안내 | 비회원은 이메일과 비밀번호를 입력하면 나중에 문의 내역을 확인할 수 있습니다. |
| 문의 유형 선택 | 문의 유형을 선택해 주십시오. |
| 제목 글자 수 초과 | 제목은 {제목 최대} 이내로 입력해 주십시오. |
| 본문 글자 수 부족 | 내용을 {본문 최소} 이상 입력해 주십시오. |
| 첨부 제한 | {첨부 제한} 파일만 올릴 수 있습니다. (팝업 D8) |
| 운영 안내 | 욕설·비방·허위 사실이 포함된 문의는 등록이 제한되며, 답변하지 않을 수 있습니다. |
| 등록 완료 | 문의 등록이 완료되었습니다. 문의번호는 {문의번호}입니다. (팝업 N1) |
| 연속 등록 제한 | 짧은 시간에 여러 건을 등록할 수 없습니다. 잠시 후 다시 등록해 주십시오. (팝업 N2) |
| 처리 상태 | 등록 / 처리 중 / 완료 |
| 비회원 열람 | 문의 등록 때 입력한 이메일과 비밀번호를 입력해 주십시오. |
| 답변 알림 | 문의하신 '{제목}'에 답변이 등록되었습니다. |

## 5. 체크리스트
- 회원·비회원 진입 방식이 나뉘어 있고, 비회원은 이메일·비밀번호를 먼저 받습니까?
- 문의 유형과 입력 제약(제목·본문·첨부) 값을 정했습니까?
- 금칙어·운영 안내가 작성 화면에 보입니까?
- 등록 후 문의 번호가 발급되고 완료 화면으로 갑니까?
- 처리 상태(등록·처리 중·완료)가 사용자에게 보입니까?
- 비회원이 이메일·비밀번호로 문의를 다시 열람할 수 있습니까?
- CAPTCHA와 연속 등록 제한이 있습니까?
- 완료 문의 보관 기간과 재문의 허용 여부를 정했습니까?
