# 비밀번호 정책

## 1. 목적
사용자가 비밀번호를 안전하게 설정하고, 잊었을 때도 쉽게 복구할 수 있도록 입력 규칙, 찾기·재설정, 변경, 보안·운영 기준을 하나로 정의한다. (웹 데스크톱 기준)
- 범위: 비밀번호 설정(가입·재설정·변경 공통) → 찾기·재설정 → 변경 → 시도 제한
- 다른 정책으로 넘김: 로그인 실패·계정 잠금(→ 로그인), 가입 화면(→ 회원가입), 팝업 문구(→ 팝업·문구 A2·A4·A5)

## 2. 규칙 표
| 유형 | 항목 | 대상 | 내용 | 등급 | {변수} |
|---|---|---|---|---|---|
| 비밀번호 설정 | 입력 규칙 | 공통 | {비밀번호 규칙: 영문·숫자·특수문자 조합 8자 이상}으로 정한다. 규칙은 입력 전부터 helper text로 상시 보여 준다. 아이디, 연속·반복 문자열은 쓸 수 없다 | 필수 | 비밀번호 규칙 |

| 찾기·재설정 | 본인 확인 | 비회원 · 사용자 | {인증 방식: 이메일 또는 휴대폰} 중 선택해 인증한다. 인증번호 유효 시간 {유효 시간: 5분}을 안내하고 재발송은 {재발송 제한: 1분에 1회}로 제한한다. 가입 여부와 관계없이 같은 안내 문구를 쓴다 | 필수 | 인증 방식, 유효 시간, 재발송 제한 |

| 비밀번호 변경 | 자발적 변경 | 사용자 · 관리자 | 내 정보에서 현재 비밀번호를 확인한 뒤 변경한다. 새 비밀번호는 설정 규칙을 똑같이 적용한다. 슈퍼 관리자가 대신 변경하는 방법도 둘 수 있다 | 필수 | — |
| 비밀번호 변경 | 주기적 변경 안내 | 사용자 · 관리자 | {변경 주기: 90일}이 지나면 변경을 권유하고, '다음에 변경하기'를 고를 수 있게 한다 (팝업 A4) | 선택 | 변경 주기 |

| 보안/운영 | 오류 문구 | 공통 | 규칙을 어긴 항목을 구체적으로 안내한다. 계정이 있는지 유추할 수 있는 문구는 쓰지 않는다 | 필수 | — |

## 3. 흐름 (비밀번호 찾기·재설정)
![비밀번호 찾기·재설정 흐름. 진입: 로그인 화면에서 '비밀번호 찾기'를 선택하고 계정 정보를 입력합니다(가입 여부와 관계없이 같은 안내). 본인 확인: 인증 수단(이메일 또는 휴대폰)을 고르고 인증번호를 입력합니다. 연속 n회 실패하면 일정 시간 인증이 제한됩니다. 재설정: 인증에 성공하면 새 비밀번호를 입력하고(규칙 실시간 안내) 한 번 더 확인합니다(일치 여부 실시간 안내). 완료: 변경 완료를 안내하고 로그인 화면으로 이동합니다.](/flows/password.svg)

## 4. 예시 문구 (합니다체)
| 상황 | 문구 |
|---|---|
| 비밀번호 helper text | {비밀번호 규칙}으로 입력해 주십시오. |
| 규칙 미충족 | 특수문자를 1개 이상 포함해 주십시오. |
| 아이디 포함 | 비밀번호에 아이디를 포함할 수 없습니다. |
| 확인 불일치 | 비밀번호가 일치하지 않습니다. |
| 찾기 계정 정보 입력 후 | 입력한 정보로 가입된 계정이 있으면 인증번호를 보내 드립니다. |
| 인증번호 발송 | 인증번호를 보냈습니다. {유효 시간} 안에 입력해 주십시오. |
| 인증 제한 | 인증에 여러 번 실패해 {제한 시간} 동안 이용할 수 없습니다. ({남은 시간} 후 가능) |
| 이전 비밀번호 재사용 | 이전에 사용한 비밀번호는 다시 쓸 수 없습니다. |
| 재설정 링크 만료 | 링크 유효 시간이 지났습니다. 비밀번호 찾기를 다시 진행해 주십시오. |
| 재설정 완료 | 비밀번호가 변경되었습니다. 새 비밀번호로 다시 로그인해 주십시오. (팝업 A5) |
| 주기적 변경 안내 | 비밀번호를 {변경 주기} 동안 변경하지 않았습니다. (팝업 A4) |
| 변경 완료 후 | 다른 기기에서는 로그아웃됩니다. |

## 5. 체크리스트
- 비밀번호 규칙을 정했고, 입력 전부터 helper text로 보이는가
- 충족한 규칙이 아이콘과 텍스트로 함께 표시되는가 (색만으로 구분하지 않음)
- 찾기 화면 문구가 가입 여부를 드러내지 않는가
- 인증번호 유효 시간·재발송 제한·시도 제한이 화면에 보이는가
- 재설정 링크가 1회용이고 유효 시간이 있는가
- 재설정 후 자동 로그인 없이 로그인 화면으로 가는가
- 변경 후 다른 기기 세션 종료와 알림 메일이 있는가
- 오류 시 해당 입력창으로 초점이 가고, 비밀번호 관리자 자동 완성이 되는가
