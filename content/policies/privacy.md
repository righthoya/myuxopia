# 개인정보 처리 정책

## 1. 목적
사용자의 개인정보를 필요한 만큼만 수집하고 안전하게 표시·관리할 수 있도록 수집·동의, 표시·마스킹, 열람·수정·삭제, 보관·파기·보안 기준을 일관되게 정의한 UX 정책 체계 (웹 데스크톱 기준)

## 2. 규칙

### 수집·동의 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 개인정보 수집·이용 동의 | 동의서에는 수집 목적·항목·보유 기간·거부 권리와 불이익 4가지를 고지<br>필수·선택 항목을 나눠 받고, 선택 항목은 거부해도 서비스 이용 가능<br>광고성 정보 수신 동의는 개인정보 동의와 별도 항목으로 받음<br>가입 화면의 동의 UI(전체 동의·전문 보기)는 회원가입 정책 참고 | 공통 |
| 최소 수집 원칙 | 목적 달성에 필요한 항목만 수집<br>입력 항목 옆에 수집 목적 안내 | 공통 |
| 동의 기록 | 동의 일시와 약관 버전 기록<br>약관 변경 시 재동의 안내 | 공통 |

### 표시·마스킹 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 마스킹 표시 | 이름·연락처·이메일은 화면에서 기본 마스킹 표시 | 공통 |
| 노출 제한 | URL, 알림 본문, 오류 문구에 개인정보 포함 금지 | 공통 |

### 열람·수정·삭제 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 내 정보 열람·수정 | 내 정보에서 수집 항목 열람·수정<br>수정 시 비밀번호 재입력 등 본인 확인 | 사용자 |
| 동의 철회·회원 탈퇴 | 선택 동의는 철회 즉시 반영<br>탈퇴 전 삭제 항목과 보관 항목 안내 | 사용자 |
| 처리 현황 확인 (추가 제안) | 제3자 제공·위탁 현황 확인 제공<br>개인정보처리방침 링크 연결 | 사용자 |

### 보관·파기·보안 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 보관·파기 | 목적 달성 시 지체 없이 파기<br>법령상 보관 항목은 별도 보관하고 기간 안내 | 공통 |
| 접근 이력 관리 | 조회·변경·다운로드 이력 기록<br>관리자 화면에서 이력 조회 | 관리자 |
| 처리방침 안내 | 푸터에 개인정보처리방침 상시 노출<br>변경 시 공지와 개정 이력 제공 | 공통 |

## 3. 흐름 — 개인정보 수집 동의 플로우
(단계·화면·분기 이름 순서, 연결 관계는 피그마 흐름도 참고)
- 진입
- 동의
- 완료
- 개인정보 입력 화면 진입 (가입·문의 등)
- 수집 항목·목적 안내 (필수·선택 구분)
- 필수 항목 동의 확인
- 선택 항목 동의 (거부 가능)
- 진행 불가 안내 (필수 항목 미동의)
- 동의 일시·약관 버전 기록
- 가입·요청 처리 완료 (내 정보에서 동의 철회 가능)
- 분기: 동의 / 미동의
