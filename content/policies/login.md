# 로그인·인증 정책

## 1. 목적
사용자가 서비스에 안전하고 빠르게 접근할 수 있도록 로그인 방식, 보조 기능, 로그인 후 연결, 보안 기준을 일관되게 정의한 UX 정책 체계 (웹 데스크톱 기준)

## 2. 규칙

### 로그인 방식 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 기본 로그인 (아이디·비밀번호) | 아이디·비밀번호 입력 후 Enter 키로 로그인 실행<br>입력 규칙·표시/숨김 토글·접근성 기준은 비밀번호 정책 참고<br>플레이스홀더 문구는 팝업·문구 공통 규칙 참고 | 공통 |
| SNS 간편 로그인(선택) | 카카오·네이버·구글 등 사용량 기준 순서로 노출<br>팝업 또는 리다이렉트 방식으로 인증, 팝업 차단 시 안내 문구 제공<br>같은 이메일 계정 연결·간편 가입 처리는 회원가입 정책 참고 | 사용자 |
| 패스키 인증 (선택) | WebAuthn 기반 패스키 지원 환경에서만 노출<br>미지원 환경은 기본 로그인으로 대체<br>기기 등록·삭제는 내 정보에서 관리 | 사용자 |

### 로그인 보조 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 최근 로그인 방식 안내 | 마지막으로 사용한 로그인 방식을 강조 노출<br>다른 방식 선택 가능 | 사용자 |
| 다중 계정 전환 | 로그인 후 계정 메뉴에서 전환 제공<br>전환 시 현재 작업 저장 여부 확인 | 사용자 |
| 아이디 저장 | 체크박스로 아이디 저장 제공, 기본값 해제<br>로그인 상태 유지는 제공하지 않음 (로그인할 때마다 비밀번호 입력)<br>공용 기기 사용 시 아이디 저장 주의 안내 | 사용자 |

### 로그인 후 연결 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 원래 작업으로 복귀 | 로그인 필요 기능 접근 시 로그인 후 해당 화면·작업으로 복귀<br>입력 중이던 정보는 유지 | 공통 |
| 로그인 필요 안내 | 비로그인 상태에서 제한 기능 접근 시 안내 문구와 로그인 버튼 노출<br>안내 후 취소 시 기존 화면 유지 | 비회원 |
| 기본 이동 화면 | 복귀할 작업이 없으면 권한별 기본 화면으로 이동<br>사용자는 메인, 관리자는 대시보드 | 사용자 · 관리자 |

### 보안/운영 정책

| 항목 | 내용 | 대상 |
|---|---|---|
| 로그인 실패 처리 | 공통: 계정 존재 여부를 알 수 없도록 통일된 오류 문구, 남은 시도 횟수 안내<br>B2C: 연속 실패 {3회} 시 CAPTCHA, {5회} 시 {30분} 로그인 제한 후 자동 해제<br>B2B: 연속 실패 {5회} 시 계정 잠금, 관리자가 잠금 해제 (CAPTCHA 미사용)<br>잠금·제한 중에도 비밀번호 재설정은 가능 | 공통 |
| 세션 만료 | 비활동 {30분} 후 자동 로그아웃, 만료 {5분} 전 경고와 연장 버튼 제공 (팝업 S1·S2)<br>만료 시 로그인 화면으로 이동하며 로그인 후 원래 작업 복귀 지원 | 공통 |
| 2단계 인증 (선택) | 관리자 계정·민감 정보를 다루는 서비스에 권장<br>비밀번호 확인 후 휴대폰 또는 이메일 인증번호 입력<br>패스키와는 별개 기능, 인증번호 규칙은 비밀번호 정책의 인증 기준 참고 | 관리자 · 사용자 |

## 3. 흐름 — 로그인 플로우
(단계·화면·분기 이름 순서, 연결 관계는 피그마 흐름도 참고)
- 진입
- 인증
- 완료
- 비로그인 사용자
- 로그인 화면 진입 (직접 진입 / 로그인 필요 기능 접근)
- 기본 로그인 (아이디·비밀번호)
- SNS 간편 로그인 (카카오·네이버·구글)
- 패스키 인증 (지원 환경에서만 노출)
- 간편 가입 연결 (같은 이메일 계정이 있으면 연결 안내)
- 인증 성공
- 원래 페이지·작업으로 복귀
- 기본 화면으로 이동 (사용자 메인 / 관리자 대시보드)
- 분기: 가입 이력 없음 / 있음
- 분기: 복귀 작업 있음 / 없음
