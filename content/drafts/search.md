# 검색·필터링 정책

## 1. 목적
검색·필터·정렬 방식을 통일해 원하는 정보를 빠르게 찾게 합니다.

## 2. 규칙 표
| 유형 | 항목 | 대상 | 내용 | 등급 | {변수} |
|---|---|---|---|---|---|
| 검색 | 통합 검색창 | 공통 | 콘텐츠·상품을 하나의 입력창에서 검색합니다. 카테고리 구분 없이 하나의 검색 흐름을 제공하고, 검색창은 {검색창 위치: 상단 헤더}에 고정해 둡니다 | 필수 | 검색창 위치 |
| 검색 | 자동완성·추천 키워드 | 사용자 | 입력 중 실시간으로 자동완성을 보여 줍니다. 현재 탭·위치에 맞는 추천 키워드를 먼저 보여 주고, 사용자 데이터를 기반으로 우선순위를 다시 배열할 수 있습니다 | 권장 | — |
| 검색 | 플레이스홀더 | 공통 | '레이블명 + 입력해주세요.' 형식으로 씁니다. 레이블이 없으면 검색할 수 있는 범위를 알려 줍니다. 레이블과 같은 문구를 플레이스홀더에 반복하지 않습니다 | 필수 | — |
| 검색 | 검색 결과 없음 | 공통 | 입력한 검색어와 함께 결과가 없음을 알리고, 철자 확인이나 다른 검색어를 제안합니다 | 권장 | — |
| 필터링 | 필터 순서 | 공통 | 필터는 {필터 순서: 큰 단위 > 중간 단위 > 작은 단위} 순으로 둡니다. 사용량에 따라 순서를 조정할 수 있습니다 (데이터 분석 도구 필요) | 권장 | 필터 순서 |
| 필터링 | 필터 일관성 | 공통 | 상품·콘텐츠에 같은 필터 구조를 씁니다. 다중 선택 여부를 정해 화면에 드러내고, 적용된 필터 상태(선택 항목, 개수)를 보여 줍니다 | 필수 | — |
| 필터링 | 정렬 | 공통 | 정렬 옵션 개수를 제한합니다. {정렬 옵션: 최신순 · 등록순 · 추천순 · 이름순}. 추천순처럼 기준이 드러나지 않는 옵션은 기준을 설명합니다. 누르면 바로 반영하고, 현재 정렬 상태를 표시합니다 | 필수 | 정렬 옵션 |
| 필터링 | 접근성 | 공통 | 자동완성은 키보드(위·아래 이동, Enter 선택, Esc 닫기)로 쓸 수 있게 합니다. 결과 개수 변화를 스크린리더에 알리고, 선택된 필터·정렬은 색만으로 구분하지 않습니다 | 필수 | — |

## 3. 예시 문구 (합니다체)
| 상황 | 문구 |
|---|---|
| 레이블 있는 검색창 플레이스홀더 | 상품명을 입력해주세요. |
| 레이블 없는 검색창 플레이스홀더 | 상품·콘텐츠 검색 |
| 검색 결과 개수 | '{검색어}' 검색 결과 {개수}건 |
| 검색 결과 없음 | '{검색어}'에 대한 검색 결과가 없습니다. 철자를 확인하거나 다른 검색어를 입력해 주십시오. |
| 추천 키워드 제목 | 추천 검색어 |
| 적용된 필터 | 필터 {개수}개 적용 |
| 필터 초기화 | 필터 초기화 |
| 필터 결과 없음 | 선택한 조건에 맞는 결과가 없습니다. 필터를 줄여 보십시오. |
| 추천순 기준 설명 | 추천순은 {추천 기준} 순서로 보여 드립니다. |

## 4. 체크리스트
- 검색창이 하나이고, 모든 화면에서 같은 위치에 있습니까?
- 플레이스홀더가 '레이블명 + 입력해주세요.' 형식이거나 검색 범위를 알려 줍니까?
- 자동완성이 키보드로 동작합니까? (위·아래, Enter, Esc)
- 검색 결과 없음 화면에 다음 행동 제안이 있습니까?
- 상품·콘텐츠의 필터 구조가 같습니까?
- 적용된 필터와 현재 정렬 상태가 화면에 보입니까? (색만으로 구분하지 않음)
- 정렬 옵션 수가 제한되어 있고, 추천순 기준을 설명합니까?
